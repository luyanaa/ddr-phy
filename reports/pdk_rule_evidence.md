## Why 8 rules remain TBD

- **PAD_PITCH** (related_rule_only): 75um is one IO CELL width, not a bond-pad pitch. Pitch is set by package/assembly rules absent from the PDK; .mag units need magscale interpretation. Keep TBD.
- **PAD_OPENING** (related_rule_only): GR.11 states the topology but gives no dimension; glass bbox is in magic internal units needing magscale. No verified micron value. Keep TBD.
- **ESD_AREA_MIN** (related_rule_only): ESD.5a is a DRC MINIMUM for the ESD IMPLANT LAYER polygon area, NOT an ESD qualification target (HBM/MM diode area). constraints uses ESD_AREA_UP/DN as diode areas; filling 0.49um2 would falsely imply a tiny diode suffices. Do NOT fill.
- **METAL_JMAX** (not_in_pdk): No Jmax / current-density / electromigration limit anywhere in libs.tech or the IO library (only a comment mentioning IR drop in librelane/config.tcl). Metal EM limits are foundry-confidential in this open PDK. Keep TBD.
- **IO_CURRENT** (design_input): Pad drive current is a DESIGN SPEC (SSTL-2 Class I 7.6mA / Class II 15.2mA), not a PDK rule. See specs/pads/device_backends.yaml sstl2_target. Keep TBD.
- **GUARD_RING_RULE_MIN** (related_rule_only): GR.2/4/6 are SEAL-RING / guard-ring-MARKER rules (distance from chip edge to core), not the latch-up tap-to-diffusion spacing that this parameter names. Different physics. Do NOT fill.
- **DQ_BIT_SKEW_MAX** (design_input): Bit-to-bit skew budget comes from the P0-1 timing contract / board SI, not from a PDK rule. Keep TBD.
- **RAIL_WIDTH** (design_input): VDDIO rail width is an EM/IR design decision requiring METAL_JMAX and IO_CURRENT, both TBD. Keep TBD.
